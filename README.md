# Omenka Industries Ltd Sales and Profitability Analysis

## Project Overview
This data analysis project provides an end-to-end evaluation of sales performance, revenue metrics, and product profitability for Omenka Industries Ltd. Leveraging Microsoft Excel and Power Query for data cleaning and Power BI for interactive visualization, the project delivers actionable business intelligence around revenue growth, order distributions, quarterly profit margins, and year-over-year performance trends.

## Data Sources
Primary records containing transaction details, product categories (Accessories, Computing, Electronics, Mobile, Office), annual timeframe metrics (2022–2025), order quantities, sales revenue, and profit metrics.

## Data Cleaning & Preparation
* **Data Inspection & Standardisation:** Standardized product titles, category classifications, and temporal tags across multi-year data.
* **Missing Value Handling:** Replaced missing values and null entries in revenue/cost metrics using targeted imputation logic.
* **Formatting:** Converted numeric fields into standard currency formats, percentages, and performance metrics for dynamic filtering.
## Interactive Visualization & Dashboard
The dynamic Power BI dashboard provides executive visibility into overall profitability, product order distributions, quarterly financial trends, and category performance.

### Key Metrics & Visual Features
* **KPI Summary Cards:** Total Revenue ($9.64M), Total Profit ($3.04M), Profit Margin (46.14%), Sales LY ($7.12M), Total Orders (2,500), and Sales YoY % (35.34%).
* **Total Revenue, Total Profit, and Sales LY by Category:** Bar/column charts contrasting total revenue, total profit, and last year's sales across key categories (Office, Computing, Mobile, Accessories, Electronics).
* **Total Profit by Quarter & Year:** Column and donut visual layouts tracking quarterly profit margins (Q1–Q4) alongside year-over-year profit distribution (2022–2025).
* **Total Orders by Product:** Detailed bar visual breakdown isolating order quantities across specific inventory items (Office Chair, Headphones, External SSD, Smartphone, Keyboard, etc.).
* **Total Profit by Month:** Line/column trends tracking financial output across monthly cycles (Jan–Dec).
